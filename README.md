# CLASSMATE SUS

20명까지 접속할 수 있는 실시간 온라인 어몽어스 스타일 학교 게임 기본 프로젝트입니다.

## 실행
1. 컴퓨터에 Node.js 18 이상 설치
2. 이 폴더에서 터미널 열기
3. `npm install`
4. `npm start`
5. 브라우저에서 `http://localhost:3000` 접속

## 친구들과 온라인으로 하려면
서버를 인터넷에 배포해야 합니다. 이 폴더 전체를 Node.js 지원 호스팅 서비스에 배포한 뒤 생성된 공개 주소를 친구들에게 공유하세요. 같은 주소로 접속하면 방 코드로 함께 들어올 수 있습니다.

## 현재 구현
- 방 생성 및 4자리 코드 참가
- 최대 20명 로비
- 최소 4명 시작, 임포스터 무작위 배정
- 크루원 미션 진행
- 긴급 회의 및 투표
- 승리 조건 및 접속 종료 처리

현재는 기본 플레이 프로토타입입니다. 실제 상용 어몽어스의 이동·킬·신고·채팅·맵 기능 전체를 복제한 버전은 아닙니다.
